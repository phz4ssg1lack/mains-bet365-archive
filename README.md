# mains-bet365-archive

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面，内容涵盖不同时期、不同主题的静态网页资源。这些页面以文件形式保存，不依赖任何特定域名或在线服务，仅作为历史版本与页面结构的存档参考。

## 目录结构说明

```
mains-bet365-archive/
├── pages/          # 页面归档目录
│   ├── ver1/       # 早期版本页面
│   ├── ver2/       # 后续更新页面
│   └── ...
├── assets/         # 页面引用的静态资源（图片、样式、脚本等）
├── index.html      # 仓库索引页（可选）
└── README.md       # 本文件
```

- `pages/`：存放所有归档的 HTML 页面，按版本或时间组织子目录。
- `assets/`：页面所使用的公共资源，避免重复存储。
- `index.html`：可选的主页，用于列出仓库内全部归档页面。

## 页面归档说明

- 每个页面均为独立完整的 HTML 文件，可直接在浏览器中打开查看。
- 页面可能包含外部资源引用（如字体、库文件），建议在本地网络环境下使用。
- 归档文件保留原始结构与内容，不进行额外修改或优化。
- 部分页面可能因时间久远而包含过时的技术或样式，仅供参考学习。

## 维护说明

- 本仓库不定期更新，新增页面会按时间顺序放入对应子目录。
- 不接受针对特定网站或服务的功能请求，仅负责页面归档本身。
- 如发现页面无法正常显示或存在明显错误，欢迎提交 Issue 说明。
- 欢迎通过 Pull Request 提交新的归档页面，但需确保内容合法合规且不涉及敏感信息。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 进入 `pages/` 目录，选择感兴趣的 HTML 文件。
3. 使用浏览器直接打开文件即可查看。
4. 如需在本地搭建简单服务器，可使用 `python -m http.server` 等工具。
